Behind the project

Two perspectives.
One shared journey.

The React Native prototype connects passengers who want to travel in their own vehicle with nearby designated drivers. Its original flows include rider and driver profiles, ride requests, pickup-code confirmation, trip status, and reviews.

The mobile app uses Expo, Firebase, and Google Maps. This browser adaptation demonstrates the interaction without accounts, API keys, or a running server.
